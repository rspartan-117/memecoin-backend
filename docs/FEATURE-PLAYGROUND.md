### AI-Powered Website Data Extraction

Extract any custom data point from company websites using natural language.

**What You Can Extract:**
- **Pricing Information**: Starting prices, plan tiers, feature breakdowns
- **Company Data**: Team size, founding date, locations, funding rounds
- **Product Details**: Feature lists, specifications, use cases
- **Contact Information**: Phone numbers, email addresses, support channels
- **Business Metrics**: Customer counts, transaction volumes, growth stats

**How It Works:**
1. Specify the domain (e.g., "stripe.com")
2. Describe what data you want in plain English
3. Provide an example of the expected format
4. AI scans relevant pages and extracts the information
5. Returns structured data in seconds

**Real-World Applications:**
- Sales teams: Auto-populate CRM with prospect data
- Researchers: Gather pricing data across 100 competitors in hours
- Content writers: Extract company facts for articles
- Investors: Analyze company metrics across portfolios
- Recruiters: Gather company size and culture information

**Example Query:**
```
Domain: "notion.so"
Extract:
- Starting price (e.g., "$8/user/month")
- Number of users (e.g., "50 million")
- Key features (list format)
- Integration count (number)
- Founded year (date format)
```

- Start with fast models for iteration
- Use premium models for final outputs
- Adjust inference steps based on complexity
- Use seeds to maintain consistency
- Generate multiple variations and select best
